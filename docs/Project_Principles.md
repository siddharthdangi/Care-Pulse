# 2. Teacher Module

Teachers should be able to:

- View timetable
- Set the class occupied or free
- alert the CR
- request for class allocation
- Post announcements
- Send notifications

---

# 3. Class Representative (CR)

Additional permissions:

- Publish class announcements
- Manage community discussions
- Create polls
- Coordinate events
- Maintain the Lost & Found section
- Manage marketplace listings
- Forward issues to the CC
- Pin important posts

## Reports

# 7. Attendance Management

The system should:

- Create attendance sessions
- Validate attendance
- Prevent duplicate attendance
- Store attendance history
- Allow attendance correction
- Generate attendance analytics
- Predict atten dance shortage
- Notify students with low attendance
- Support attendance verification mechanisms
- Support future anti-proxy mechanisms

---

# 8. Assignment Management

## Teachers should be able to:

- Create assignments
- Set deadlines
- Attach files
- Edit assignments

## Students should be able to:

- Submit assignments
- Replace submissions before the deadline
- View grades
- View feedback

## The system should:

- Track assignment deadlines
- Notify upcoming deadlines
- Notify overdue assignments

# 9. Notes Management

## Teachers should be able to:

## Students should be able to:
